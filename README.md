# Gå Appen (web demo)

Dette er en enkel web-versjon (MVP) av **Gå Appen**: registrering + kart (Pokémon Go-stil) + “Start dagens tur” + poeng for **gåing/sykling**.

## Kjøre lokalt

- Åpne `index.html` i nettleseren.
- For best GPS: åpne på mobil (Chrome/Safari) og gi posisjonstilgang.

## Gjør den “proff” med Supabase (online toppliste)

For ekte konkurranse per skole/kommune (alle ser samme toppliste), bruker vi **Supabase**.

### 1) Opprett prosjekt

- Lag et Supabase-prosjekt
- Finn:
  - **Project URL**
  - **Anon public key**
- Lim dem inn i appen: `Profil` → **Online konkurranse (Supabase)** → Lagre

### 2) Lag tabeller (SQL)

Kjør dette i Supabase SQL Editor:

```sql
-- Profiles: hvem brukeren er og hvilken skole/kommune de tilhører
create table if not exists public.profiles (
  id uuid primary key references auth.users(id) on delete cascade,
  created_at timestamptz not null default now(),
  display_name text not null,
  email text,
  kommune text not null,
  skole text not null
);

-- Daily stats: daglige poeng + distanse (kilde for sesongsummer)
create table if not exists public.daily_stats (
  id bigint generated by default as identity primary key,
  created_at timestamptz not null default now(),
  user_id uuid not null references auth.users(id) on delete cascade,
  date_key date not null,
  points integer not null default 0,
  active_meters integer not null default 0,
  constraint daily_stats_unique unique (user_id, date_key)
);

-- Published season scores: enkel leaderboard (kan senere erstattes av view/materialized view)
create table if not exists public.season_scores (
  id bigint generated by default as identity primary key,
  created_at timestamptz not null default now(),
  user_id uuid not null references auth.users(id) on delete cascade,
  season_key text not null,
  skole text not null,
  kommune text not null,
  points integer not null default 0,
  active_meters integer not null default 0,
  constraint season_scores_unique unique (user_id, season_key)
);
```

### 3) Slå på RLS (sikkerhet)

```sql
alter table public.profiles enable row level security;
alter table public.daily_stats enable row level security;
alter table public.season_scores enable row level security;

-- Profiles: alle kan lese (for topplister), bare eier kan skrive sin egen profil
create policy "profiles_read_all"
on public.profiles for select
to anon, authenticated
using (true);

create policy "profiles_write_own"
on public.profiles for insert
to authenticated
with check (auth.uid() = id);

create policy "profiles_update_own"
on public.profiles for update
to authenticated
using (auth.uid() = id)
with check (auth.uid() = id);

-- Daily stats: bare eier kan lese/endre sine egne
create policy "daily_stats_read_own"
on public.daily_stats for select
to authenticated
using (auth.uid() = user_id);

create policy "daily_stats_write_own"
on public.daily_stats for insert
to authenticated
with check (auth.uid() = user_id);

create policy "daily_stats_update_own"
on public.daily_stats for update
to authenticated
using (auth.uid() = user_id)
with check (auth.uid() = user_id);

-- Season scores: alle kan lese for leaderboard, bare eier kan skrive sin egen
create policy "season_scores_read_all"
on public.season_scores for select
to anon, authenticated
using (true);

create policy "season_scores_write_own"
on public.season_scores for insert
to authenticated
with check (auth.uid() = user_id);

create policy "season_scores_update_own"
on public.season_scores for update
to authenticated
using (auth.uid() = user_id)
with check (auth.uid() = user_id);
```

### 5) “Kår vinner” (hvert kvartal)

I en proff versjon gjør dere kåringen på server, så ingen kan fake “jeg vant”.

En enkel løsning er å lage et view som alltid viser dagens vinner per skole per sesong:

```sql
create or replace view public.season_winners as
select distinct on (season_key, skole)
  season_key,
  skole,
  kommune,
  user_id,
  points,
  active_meters,
  created_at
from public.season_scores
order by season_key, skole, points desc, active_meters desc, created_at asc;
```

Merk: for “ekte vinner” trenger dere typisk en mer presis query (top 1 per skole) eller en scheduled job som låser vinnere ved sesongslutt.

### 4) Auth (innlogging)

I Supabase Dashboard:
- Authentication → Providers → slå på **Email**
- (Valgfritt) slå på “confirm email” og tilpass maler.

## Hvordan poeng fungerer (demo)

- Nettleseren gir GPS-posisjon og ofte fart (m/s). Hvis fart ikke finnes estimeres den av distanse/tid.
- Aktivitet klassifiseres grovt:
  - **Går**: 0.6–2.2 m/s
  - **Sykler**: 2.2–7.0 m/s
  - **Kjøretøy**: > 7.0 m/s (gir 0 poeng)
- Poeng:
  - Går: ca. 10 poeng per km
  - Sykler: ca. 6 poeng per km

## Viktig

Denne demoen lagrer registrering/poeng **kun lokalt** (LocalStorage). For en ekte konkurranse per kommune/skole trenger dere en backend (innlogging, personvern, foreldresamtykke, anti-juks, osv.).
